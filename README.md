## List of Tools

- [**Firefox Launcher**](./firefox-launcher.applescript): AppleScript that always launches a new Window for the Firefox Web Browser **(BROKEN!?)**
- [**Kitty Launcher**](./kitty-launcher.applescript): AppleScript that always launches a new Window for the Kitty Terminal
- [**Neovim Kitty Launcher**](./neovim-kitty-launcher.applescript): AppleScript that launches the Kitty Terminal with Neovim (and optionally a file), can be used with *Automator* or *Shortcuts* to build a Program to use as the default Text Editor in MacOS
